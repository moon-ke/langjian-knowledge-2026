大四最后一学期每月任务清单：毕业倒计时

大四最后一学期是我人生中最忙的半年。

秋招、春招、毕业论文、各种手续……一堆事情堆在一起，差点没把我搞疯。

今天给你们整理一份每月任务清单，让你们心里有数。

时间总览

第一学期（9-12月）：秋招冲刺 + 毕业论文开题 + 期末考试

第二学期（1-6月）：春招求职 + 毕业论文 + 毕业手续 + 离校

九月：启动

秋招是重头戏

9月开始，大厂陆续开放秋招通道。

这个月要完成的事情：

  • 简历打磨完成（至少改过5遍）
  • 目标公司列表列出来（至少20家）
  • 开始投递简历
  • 准备笔试（行测、专业知识）

毕业论文开题

9月要开始考虑毕业论文的方向：

  • 跟导师初步沟通研究方向
  • 阅读相关文献
  • 确定选题
  • 写开题报告

其他

  • 确认大四上学期的课程
  • 补考（如有）

十月：秋招高峰

秋招继续

这是秋招最密集的阶段：

  • 参加各大公司宣讲会
  • 笔试、群面、单面
  • 拿到offer
  • 做出offer选择

毕业论文

  • 完成开题报告
  • 准备开题答辩PPT
  • 开题答辩

其他

  • 确认保研/考研资格（如有）
  • 准备简历

十一月：秋招收尾

秋招收尾

  • 做出offer决策
  • 签三方协议
  • 还没offer的，准备春招

毕业论文

  • 开始写文献综述
  • 开始做实验/调研

其他

  • 期末考试复习
  • 处理三方协议违约金问题（如有）

十二月：期末 + 秋招总结

期末考试

  • 复习期末考试
  • 参加期末考试
  • 不挂科

秋招总结

  • 总结秋招经验
  • 准备春招

毕业论文

  • 继续做毕业论文

其他

  • 准备回家过年

一月：寒假

这是春招前的最后准备时间。

  • 复盘秋招失败原因
  • 改进简历
  • 练习面试技巧
  • 准备春招

毕业论文

  • 写文献综述
  • 写研究框架

二月：春节 + 春招启动

春节在2月，利用假期准备春招。

  • 刷面经
  • 改简历
  • 做模拟面试

毕业论文

  • 开始写论文正文

三月：春招高峰

春招开始

3月开始，春招陆续开放：

  • 开始投递春招岗位
  • 参加春招笔试面试
  • 还没offer的，继续努力

毕业论文

  • 交初稿给导师
  • 根据导师意见修改

其他

  • 毕业生信息采集（拍照）
  • 就业推荐表盖章

四月：春招 + 论文修改

春招继续

  • 参加更多春招面试
  • 拿到offer
  • 做出offer选择

毕业论文

  • 论文修改
  • 论文查重
  • 论文定稿

其他

  • 三方协议签订（如果签了的话）

五月：毕业手续

这是毕业手续最密集的月份。

  • 就业推荐表盖章
  • 实习协议处理
  • 毕业生登记表填写
  • 确认档案去向

毕业论文

  • 论文最终定稿
  • 论文答辩准备

其他

  • 拍毕业照
  • 各种证明材料办理

六月：答辩 + 离校

毕业论文答辩

  • 准备答辩PPT
  • 论文答辩
  • 根据答辩意见修改论文

毕业典礼

  • 参加毕业典礼
  • 领取毕业证书和学位证书

离校手续

  • 退宿舍（把钥匙交回去）
  • 图书馆还书
  • 饭卡注销
  • 团组织关系转移
  • 档案转递确认

其他

  • 跟同学告别
  • 寄行李回家
  • 正式入职/开始新生活

过来人的血泪教训

教训一：秋招比春招重要

秋招的HC比春招多很多，一定要全力以赴秋招。

春招是补充，能秋招搞定就不要等春招。

教训二：毕业论文要早点开始

不要拖到最后一个月写，根本写不完。

建议提前一个学期开始，留足够的时间修改。

教训三：毕业手续不要拖

毕业手续很多，每一项都有截止日期。

错过截止日期，可能影响毕业。

教训四：三方协议看清楚再签

违约金、工作地点、岗位……签之前一定要看清楚。

签了之后再想毁约，成本很高。

教训五：档案和团组织关系要处理好

这两个东西很多人忽视了，结果考公政审的时候才发现问题。

提前了解流程，确保档案顺利转到正确的地方。

最后说几句

大四最后一学期是大学四年最忙的半年。

秋招、春招、毕业论文、毕业手续……一堆事情堆在一起。

但只要做好规划，一步一步来，都能搞定。

珍惜大学最后半年，多跟同学聚聚，多跟老师聊聊。

毕业之后，你会发现最怀念的，还是大学时光。
