暑假技能树：PPT、Python、Excel，一个暑假全搞定

暑假技能树：PPT、Python、Excel，一个暑假全搞定

很多人问我：大学除了上课，还能学什么实用技能？

说实话，PPT、Python、Excel，这三样东西，如果你暑假能搞定，进入大学之后你会发现你能碾压80%的同学。不是夸张，是真的。

为什么？因为大多数新生这三种东西都是零基础。你提前学一点，开学之后你就是”那个会做PPT的同学”、“那个会写代码的同学”、“那个Excel玩得很溜的同学”——这些标签在学生会、社团、班委竞选里，都是加分项。

而且，这三样东西不需要你有多聪明，暑假两个月，每天2小时，足够你从零到入门了。

为什么是这三样技能

先说为什么选这三样。

PPT是展示工具。不管你做什么，最后都要”讲”给别人听。课程汇报、社团竞选、比赛答辩、科研展示——一个好看的PPT能让你的内容增色不少。

Python是效率工具。我用它批量处理过 hundreds of files，也用它爬过数据、写过自动化脚本、打过比赛。很多同学花三小时做的表格，我用Python半小时搞定。

Excel是数据工具。大学四年你会遇到无数需要整理、分析、展示数据的时候。期末成绩统计、社团人员管理、活动预算表——会用Excel的人在这些事情上花的时间只有不会用的人的三分之一。

这三样东西，学会一件就能甩开一批人，全学会你就是全能选手。

8周完整学习计划

先给你一个总览，然后我再详细讲每个技能怎么学。

第1-2周：PPT（每天1小时基础知识 + 周末2小时实战项目）

第3-4周：Python基础（每天1小时基础知识 + 周末2小时实战项目）

第5-6周：Excel（每天1小时基础知识 + 周末2小时实战项目）

每天的学习时间不用很长，1小时够了。周末可以花2小时做实战项目。关键是坚持。

PPT：大学生最重要的门面技能

大学里有多少地方要用PPT？学生会竞选要用、社团活动策划要用、课程汇报要用、比赛答辩要用、科研展示要用——你几乎躲不开。

但大多数人做的PPT是什么样的？背景是渐变色，字体是三种以上，每页都是大段文字，配图是网上随便找的丑图。这种PPT交上去，老师和同学给你的眼神你自己能感受到。

PPT要学什么

核心三件事：配色、字体、留白。

配色

配色不用学太深，知道几个基本原则就够了：

主色+辅色+点缀色，总共不超过三种颜色。比如你选蓝色做主色，灰色做辅色，橙色做点缀色，这个搭配就很好看。

背景尽量用浅色或纯白，不要用花里胡哨的渐变色。深色背景只用在标题页和结尾页。

给你三个配色方案，直接拿去用：

第一个是专业商务风：深蓝 2C3E502C3E50 配浅灰 ECF0F1ECF0F1，加金色点缀 F39C12F39C12。这个配色做汇报、答辩、竞选都合适。

第二个是清新学术风：白色背景 FFFFFFFFFFFF，文字用深灰 #333333，重点内容用蓝绿 1ABC9C1ABC9C。这个配色干净清爽，适合课程汇报。

第三个是活力青春风：浅粉 F8E1F4F8E1F4 背景，正文用深紫 5D4E6D5D4E6D，强调用橙色 FF6F61FF6F61。这个配色适合社团活动、学生会竞选。

字体

字体是大多数人最容易犯错的。

中文PPT最多用两种字体：标题用黑体或者微软雅黑，正文用宋体或者楷体。不要混用，不要用艺术字，不要用带阴影的字体，不要用字体特效。

标题字号32-44号，正文字号18-24号，注释或副标题字号14-16号。这个比例记住就行。

英文字体推荐三种：Arial（最安全，什么场合都能用）、Helvetica（比Arial更有设计感）、Georgia（衬线体，适合文艺类PPT）。

中英文搭配的时候，中文用微软雅黑，英文用Arial，这个组合永远不会出错。

留白

这是大多数人最容易忽略的。PPT不是把内容堆上去，是把最重要的内容清晰地展示出来。

每页留出30%以上的空白。四周要有边距，内容不要太靠边。一页只讲一件事，不要把所有东西都塞进一页里。

对齐

内容要对齐。标题居中还是左对齐，整份PPT要统一。段落左对齐还是两端对齐，也要统一。最简单的方法：打开PPT的”视图-网格线和参考线”，让内容对齐到网格上。

14天详细学习计划

第1天：认识PPT

打开PowerPoint或者WPS，新建一个空白演示文稿。花30分钟熟悉界面：菜单栏在哪里、怎么插入形状、怎么插入图片、怎么添加动画。

然后去B站看一个入门视频，推荐”和珞珈学PPT”的基础教程，播放量最高的那个全集，大概3小时能看完。看的时候跟着做。

今天的目标：知道PPT是什么，能新建一个PPT，能插入文字和图片。

第2天：字体和排版

学习字体的基础知识：字号、字重、颜色、间距。

打开一个空白PPT，输入几行文字，试试不同的字号、不同的颜色、不同的行距。感受一下什么样的排版看起来舒服。

今天的目标：掌握字体设置的基本操作，知道什么样的排版是舒服的。

第3天：配色方案

学习配色原则：主色、辅色、点缀色。

找一份你喜欢的PPT（可以在”PPT超级市场”网站找模板），分析它的配色：用了什么颜色、为什么好看、哪些地方用主色、哪些地方用辅色。

今天的目标：能分析一套PPT的配色逻辑，能自己搭配一个配色方案。

第4天：图片处理

学习怎么插入图片、裁剪图片、调整图片亮度对比度。

去”unsplash.com”或”pexels.com”下载几张免费的高清图片，试着把它们放进PPT里，调整到合适的大小和位置。

今天的目标：能熟练处理图片，知道哪里能找到好看的免费图片。

第5天：图标和形状

学习插入图标和形状。

去”iconfont.cn”（阿里巴巴矢量图标库）下载几个你喜欢的图标，插入到PPT里。试试不同的形状填充方式：纯色填充、渐变填充、无填充（只有边框）。

今天的目标：能使用图标和形状，知道哪里能找到好看的免费图标。

第6天：排版练习

做一个10页的PPT练习。主题随便选，比如”我的一天”、“我的家乡”、“我最喜欢的一本书”。要求：每页只讲一件事、留白至少30%、只用两种字体、配色不超过三种。

今天的目标：独立完成一份结构清晰的PPT。

第7天：数据分析型PPT

学习怎么做数据展示：柱状图、折线图、饼图。

去国家统计局网站找一组数据（比如某省十年GDP变化），做成图表。关键是：图表的标题要写清楚、坐标轴要标注单位、数据来源要注明。

今天的目标：能制作专业的数据图表。

第8天：PPT结构设计

学习PPT的整体结构设计。

一份标准的汇报型PPT应该包含：封面页、目录页、背景介绍、核心内容（3-5页）、结论、致谢页。

今天的目标：知道一份完整PPT应该包含哪些部分，每个部分应该怎么设计。

第9-10天：实战项目——个人介绍PPT

这是一个完整的实战项目：用7天时间做一份个人介绍PPT。

Day 1：设计PPT框架和配色方案，写出每页要讲的内容大纲。

Day 2-3：做封面页和个人经历页面，学习怎么用时间轴展示经历。

Day 4-5：做技能展示和兴趣爱好页面，学习怎么用图标和图片展示技能。

Day 6：做结尾页和致谢页，统一检查所有页面的格式和配色。

Day 7：检查一遍，确认字体统一、对齐正确、配色一致，导出PDF备份。

今天的目标：完成一个完整的个人介绍PPT，这份PPT开学之后可以直接用。

第11-12天：模仿练习

找一份你特别喜欢的PPT模板（可以去”优品PPT”网站），完整地模仿一遍。不是照抄内容，是模仿它的设计：配色怎么用的、字体怎么选的、排版怎么做的。

今天的目标：能独立分析和模仿一个PPT模板的设计。

第13-14天：综合提升

学习PPT的进阶技巧：SmartArt图形、母版设计、动画基础。

今天的目标：掌握进阶功能，能独立完成一份20页以内的完整PPT。

10个常见的PPT错误

排版混乱——所有文字左对齐或者居中对齐，不要混着来。

字体超过三种——最多两种字体，多了就是灾难。

背景太花哨——白色或浅色背景最专业。

字太多——一页不要超过6行，每行不要超过6个字。

不校对错别字——发出去之前检查三遍，这是最基本的尊重。

不标注图片来源——图表、照片、数据都要注明来源。

动画太花哨——简单的淡入淡出就够了，不要用弹跳、飞入这些花哨效果。

不调整图片大小——图片变形是最常见的低级错误。

颜色太暗——浅色背景配深色文字，不要用暗色背景配暗色文字。

没有统一风格——整份PPT用同一个配色方案和字体方案，不要每页换一种风格。

Python：未来最值得投资的技能

我知道”编程”这两个字听起来很难，尤其是对文科生来说。但Python真的不一样，它的设计理念就是”简单、易学、实用”。

你不需要懂计算机原理，不需要懂数据结构，不需要懂算法——入门阶段，这些都不需要。你只需要知道：Python能帮你做什么、怎么写一个最简单的程序。

Python能做什么

自动批量处理文件——你有一百个文件需要重命名，Python写个脚本十分钟搞定。

自动爬取网页数据——写论文要做调研，Python爬虫能帮你收集数据。

数据分析——学校活动的数据、社团运营的数据，Python处理起来比Excel快十倍。

自动化办公——每天重复性的Excel整理、邮件发送，Python可以帮你自动完成。

甚至可以做个小游戏——别觉得不可能，Python的Pygame库可以让你两周做一个小游戏出来。

第8-14天：三个实战项目

这三个项目由易到难，每天做一个：

项目一：批量重命名文件

这个项目用Python自动重命名文件夹里的文件。比如你有一百张照片，想把”IMG_001.jpg”改成”照片_001.jpg”，手动改要改到崩溃，Python帮你一键搞定。

完整代码：

import os

folder_path = "C:/Users/你的用户名/Pictures/photos"

files = os.listdir(folder_path)
count = 1

for file in files:
    if file.endswith(".jpg"):
        old_name = os.path.join(folder_path, file)
        new_name = os.path.join(folder_path, f"照片_{count:03d}.jpg")
        os.rename(old_name, new_name)
        print(f"{file} -> 照片_{count:03d}.jpg")
        count += 1

print(f"完成！共重命名{count-1}个文件")

你需要修改folder_path改成你自己的文件夹路径，然后运行这个脚本，看看效果。

项目二：爬取豆瓣电影Top250信息

这个项目用Python爬取豆瓣电影Top250的电影信息，包括电影名称、评分、评价人数、经典台词。

完整代码：

import requests
from bs4 import BeautifulSoup

url = "https://movie.douban.com/top250"
headers = {"User-Agent": "Mozilla/5.0"}

response = requests.get(url, headers=headers)
soup = BeautifulSoup(response.text, "html.parser")

movies = soup.find_all("div", class_="hd")
ratings = soup.find_all("span", class_="rating_num")

for i in range(min(10, len(movies))):
    title = movies[i].find("span", class_="title").text
    rating = ratings[i].text
    print(f"{i+1}. {title} - 评分：{rating}")

安装第三方库：在命令行输入pip install requests beautifulsoup4

这个脚本能爬取豆瓣电影Top250的前10部电影信息。理解了这个脚本，你就掌握了网页爬虫的基本原理。

项目三：简单计算器GUI程序

这个项目用Python的tkinter库做一个带界面的计算器。

完整代码：

import tkinter as tk

def button_click(number):
    current = entry.get()
    entry.delete(0, tk.END)
    entry.insert(0, current + str(number))

def button_clear():
    entry.delete(0, tk.END)

def button_equal():
    try:
        result = eval(entry.get())
        entry.delete(0, tk.END)
        entry.insert(0, str(result))
    except:
        entry.delete(0, tk.END)
        entry.insert(0, "错误")

root = tk.Tk()
root.title("简单计算器")
root.geometry("300x400")

entry = tk.Entry(root, font=("Arial", 20), justify="right")
entry.grid(row=0, column=0, columnspan=4, padx=10, pady=10)

buttons = [
    "7", "8", "9", "/",
    "4", "5", "6", "*",
    "1", "2", "3", "-",
    "0", ".", "=", "+"
]

row = 1
col = 0
for button in buttons:
    if button == "=":
        tk.Button(root, text=button, font=("Arial", 16), 
                 command=button_equal).grid(row=row, column=col, sticky="nsew")
    elif button in "+-*/":
        tk.Button(root, text=button, font=("Arial", 16),
                 command=lambda b=button: button_click(b)).grid(row=row, column=col, sticky="nsew")
    else:
        tk.Button(root, text=button, font=("Arial", 16),
                 command=lambda b=button: button_click(b)).grid(row=row, column=col, sticky="nsew")
    col += 1
    if col > 3:
        col = 0
        row += 1

root.mainloop()

运行这个脚本，你会看到一个和手机计算器界面差不多的程序。理解了这个代码，你就学会了Python GUI编程的基本方法。

常见错误和解决方案

SyntaxError: 语法错误，检查一下括号、引号、冒号有没有写对，Python对格式要求很严格。

NameError: 变量名没定义，检查一下变量名拼写对不对。

IndentationError: 缩进错误，Python用缩进来表示代码块，用Tab键或者4个空格都可以，但不能混用。

TypeError: 类型错误，比如把字符串和数字加在一起，试试用str()或int()转换类型。

IndexError: 索引错误，比如列表只有3个元素你访问第5个，索引从0开始。

遇到错误不要慌，把错误信息复制到搜索引擎或者ChatGPT里，大部分问题都能找到答案。

Excel：大学四年最被低估的技能

很多人觉得Excel就是”填表格”，进了大学才知道：Excel是神器。

课程作业要做数据分析？Excel。

社团管理要做人员统计？Excel。

实习要做数据报表？Excel。

毕业设计要做数据处理？Excel。

你可能不知道，Excel玩得溜的人在大学里有多稀缺。我认识一个大三学长，Excel VBA写得飞起，被导师直接拉去做课题的数据处理，实习还没开始就已经在赚外快了。

Excel要学什么

第一层：基本操作

表格格式、数据填充、筛选、排序、简单的公式（SUM、AVERAGE、IF）。这个暑假花一周就能掌握。

第二层：函数和图表

VLOOKUP、数据透视表、各种图表的制作。数据透视表是Excel最强大的功能之一，学会之后处理几百条数据只需要几秒钟。这个大概需要两周。

第三层：进阶

Excel VBA（自动化脚本）和Power Query（数据清洗）。这个不是必须，但学会了就是加分项。

14天详细学习计划

第1天：Excel基础界面和基本操作

学习内容：认识Excel界面、单元格操作、工作表操作、数据输入。

打开Excel，新建一个空白工作簿。花30分钟熟悉界面：菜单栏、功能区、名称框、编辑栏、工作表标签。

练习：在单元格中输入文字、数字、日期；调整列宽行高；合并单元格；设置单元格背景色和字体颜色。

今天的目标：能熟练地在Excel中输入和编辑数据。

第2天：公式基础

学习内容：SUM（求和）、AVERAGE（平均值）、MAX（最大值）、MIN（最小值）、COUNT（计数）。

代码示例：

=SUM(A1:A10)      # 求A1到A10的和
=AVERAGE(B1:B10)  # 求B1到B10的平均值
=MAX(C1:C10)      # 求C1到C10的最大值
=MIN(D1:D10)      # 求D1到D10的最小值
=COUNT(E1:E10)    # 统计E1到E10有多少个数字

今天的目标：能写简单的公式进行数据统计。

第3天：IF条件函数

学习内容：IF函数、AND函数、OR函数、嵌套IF。

代码示例：

=IF(A1>=60, "及格", "不及格")  # 如果A1大于等于60显示及格，否则显示不及格
=IF(A1>=90, "优秀", IF(A1>=80, "良好", IF(A1>=60, "及格", "不及格")))  # 多层嵌套
=IF(AND(A1>=60, B1>=60), "全部及格", "有不及格")  # AND要求所有条件都满足
=IF(OR(A1>=90, B1>=90), "有单科优秀", "无单科优秀")  # OR只要有一个条件满足

今天的目标：能写IF函数进行条件判断。

第4天：VLOOKUP函数

VLOOKUP是Excel里最重要的函数之一，必须掌握。

代码示例：

=VLOOKUP(A1, 数据源!A:B, 2, FALSE)  
# 在数据源表格的A列查找A1的值，返回第2列（B列）的数据，FALSE表示精确匹配

举例：假设你有一张成绩表A列是学号，B列是姓名，C列是成绩。现在你要根据学号查找成绩，可以用：

=VLOOKUP("2023001", A:C, 3, FALSE)

这会返回学号”2023001”的成绩。

今天的目标：能写VLOOKUP函数进行数据查找。

第5天：INDEX+MATCH组合

VLOOKUP只能从左往右查，INDEX+MATCH可以双向查找，更灵活。

代码示例：

=INDEX(C:C, MATCH("张三", B:B, 0))
# 在B列找"张三"，返回对应的C列数据

这个组合看起来复杂，但记住公式结构就行：INDEX(返回哪一列, MATCH(找什么, 在哪一列找, 0))

今天的目标：能写INDEX+MATCH组合进行双向查找。

第6天：SUMIFS和COUNTIFS

这两个函数用来按条件统计，比SUMIF和COUNTIF更强大。

代码示例：

=SUMIFS(C:C, B:B, "大一", A:A, ">=80")  
# 统计大一（A列）且分数>=80的C列之和
=COUNTIFS(A:A, "大一", B:B, "男")  
# 统计大一且性别为男的人数

今天的目标：能写SUMIFS和COUNTIFS按多个条件统计。

第7天：数据透视表

数据透视表是Excel最强大的功能，没有之一。

使用方法：选中数据区域-插入-数据透视表-把字段拖到行、列、值、筛选区域。

举例：如果你有一张销售数据表，有日期、商品、销量、地区四列。把”地区”拖到行，“商品”拖到列，“销量”拖到值，数据透视表就会自动生成一个按地区和商品交叉的销量统计表。

今天的目标：能创建和使用数据透视表。

第8天：图表基础

学习内容：柱状图、折线图、饼图、柱状图的做法。

选中数据区域-插入-选择图表类型。

关键是：每种图表有不同的适用场景。柱状图适合比较数量，折线图适合展示趋势，饼图适合展示比例。

今天的目标：能创建专业的图表。

第9-10天：大学生活实战模板

模板一：期末成绩自动统计表

创建一个成绩表模板，包含：学号、姓名、高数、英语、专业课1、专业课2、总分、平均分、排名、等级。

公式设置：

总分 = 高数 + 英语 + 专业课1 + 专业课2

平均分 = 总分 / 5

排名 = RANK(总分, 总分列, 0) # 降序排列

等级 = IF(平均分>=90, “A”, IF(平均分>=80, “B”, IF(平均分>=70, “C”, IF(平均分>=60, “D”, “F”))))

加上条件格式：90分以上绿色背景，60分以下红色背景。

模板二：社团活动预算表

创建一个预算表模板，包含：项目名称、预算金额、实际支出、差额、备注。

用SUM函数统计总预算和总支出，用条件格式标注超支项目（红色）。

加上数据验证：项目名称列设置下拉菜单，限制只能选择预设的项目类型。

模板三：生活费记账本

创建一个记账模板，包含：日期、类别（餐饮/交通/购物/娱乐/其他）、金额、备注。

用数据透视表生成月度支出统计图，用SUMIFS按类别统计每月支出。

今天的目标：完成三个模板的制作，开学之后可以直接用。

第11天：图表美化

学习内容：让图表看起来专业，而不是Excel默认的丑样子。

三个图表规则：

规则一：删掉多余的网格线和图例。如果图表已经说明了”销量”，就不需要再写”销量”图例。

规则二：统一配色。图表颜色和表格配色保持一致，不要用Excel默认的彩色调色板。

规则三：简化标题。图表标题要简洁，一句话说明图表要表达的核心信息，不要写”2023年度各月销售额变化趋势分析图”这么长的标题。

今天的目标：能把Excel默认的丑图表改成专业图表。

第12天：快捷键

10个最常用的Excel快捷键：

Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+Z 撤销

Ctrl+Shift+↓ 快速选中一列、Ctrl+Shift+→ 快速选中一行

Ctrl+D 向下填充、Ctrl+R 向右填充

Ctrl+E 智能填充（根据已有规律自动填充）

F4 重复上一个操作

Ctrl+; 输入当天日期

Alt+= 快速求和

今天的目标：记住这10个快捷键，强迫自己用快捷键而不是鼠标操作。

第13-14天：综合练习

用一份真实的数据集（可以去Kaggle或者阿里天池下载公开数据集），完成从数据清洗到数据可视化到数据分析报告的全流程。

步骤一：导入数据，清洗缺失值和异常值。

步骤二：用数据透视表做统计分析。

步骤三：用图表做数据可视化。

步骤四：写一份简单的数据分析报告。

今天的目标：完成一个完整的数据分析流程。

第7-8周：综合实战项目

前六周你学了三个技能，第七周和第八周，把它们串起来用。

项目：大学数据看板

这个项目的目标是：做一个完整的”大学数据看板”，展示你自己感兴趣的某个主题的数据分析结果。

项目背景

选择一个你感兴趣的主题。比如：你所在省的近十年高考数据、某所大学的录取分数线变化、某个行业的发展趋势、某部热门电影的票房数据。

技术栈

Python：爬取数据（用requests+BeautifulSoup，或者用pandas读取公开CSV）

Excel：清洗数据、分析数据、制作图表（用数据透视表和函数）

PPT：制作汇报展示（把分析结果整理成一份20页以内的汇报PPT）

项目步骤

第一步：确定主题，收集数据（Python爬虫或下载公开数据集）

第二步：数据清洗和预处理（Excel Power Query或Python pandas）

第三步：数据分析（Excel数据透视表和统计函数）

第四步：数据可视化（Excel图表或Python matplotlib）

第五步：制作汇报PPT（把分析过程和结论整理成PPT）

预期成果

一份完整的Python数据爬取代码、一个经过清洗和分析的Excel数据文件、一份展示分析结果的PPT。

这三个东西放在一起，就是你在大学里的第一个数据项目经历。面试的时候、写简历的时候、写申请的时候，都可以用这个经历来展示你的能力。

最后说一句

我知道你们暑假想玩，想放松，想做很多”上了大学就没时间做”的事情。

这是对的。暑假的休息和放松非常重要。

但如果你每天能抽出一个半小时——不用多，一个半小时就够了——把这三样东西学一学，等你进入大学，你会发现你比大多数人从容得多。

不是说你一定要学这三样，而是：找到你觉得最有用的技能，利用暑假时间提前投入。暑假是你唯一一个有大段时间可以系统学习的窗口期，错过了，大一大二被课业和社团占满，你很难再找到整块的时间来学新东西。

选一个方向，开始学。就从今天开始。
