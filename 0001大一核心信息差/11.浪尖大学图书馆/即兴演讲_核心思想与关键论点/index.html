即兴演讲_核心思想与关键论点

《即兴演讲》核心框架：当”没有准备时间”的时候，怎么说才是对的？

说实话，汉弗莱这本书的核心论点是：即兴演讲不是”随机发挥”，而是有”结构”的——掌握了这个结构，你就能在任何场合都能清晰表达。

很多人以为”即兴演讲”是”临场发挥”，不可能提前准备。但汉弗莱告诉你：即兴演讲是可以”准备”的——不是准备”说什么”，而是准备”怎么说”。

今天给你们梳理一下这本书的核心论点。

核心论点一：即兴演讲的本质

汉弗莱认为：即兴演讲的本质是”有准备的即兴”。

“有准备”不是准备”具体的台词”，而是准备：

  • “结构”：当你被问到任何问题，你都有一个”组织语言的框架”
  • “心态”：你有自信、有条理、有感染力地表达自己
  • “技巧”：你知道一些”快速思考”和”表达”的技巧

即兴演讲不是”随机发挥”，而是”有套路的即兴”。

核心论点二：即兴演讲的”万能结构”

汉弗莱给出了即兴演讲的万能结构（Point-Reason-Example-Point，PREP）：

1. 亮观点（Point）

  • 先说你的核心观点
  • 举例：“我认为大学期间最应该培养的能力是思考能力。”

2. 说原因（Reason）

  • 再说为什么
  • 举例：“原因有三个：第一，思考能力能帮你解决任何问题；第二，思考能力是其他能力的基础；第三，思考能力能让你在竞争中脱颖而出。”

3. 给例子（Example）

  • 举例说明
  • 举例：“比如，我在做项目的时候，就是用’批判性思考’来分析问题，才能找到真正的原因。”

4. 再总结（Point）

  • 最后再重复观点
  • 举例：“所以我的观点是：大学期间最应该培养的是思考能力，它会伴随你一生。”

这个结构能让你在任何话题上都有话说——因为你总是可以”亮观点→说原因→给例子→再总结”。

核心论点三：快速思考的技巧

即兴演讲的难点是”没有时间准备”，汉弗莱给出了”快速思考”的方法：

1. 用”连接词”争取时间

  • “这个问题很好…”
  • “让我想想…”
  • “从几个方面来说…”
  • “首先我想说…”

2. 用”框架”组织语言

  • “第一、第二、第三”
  • “先说、再讲、最后”
  • “一方面、另一方面”
  • “过去、现在、未来”

3. 用”简短回答”开始

  • 先说一个”简短的观点”，再展开
  • 不要追求”面面俱到”，追求”重点突出”

核心论点四：自信表达的要素

汉弗莱指出：即兴演讲的关键不是”说什么”，而是”怎么说”。

自信表达的要素：

1. 声音

  • 声音稳定，不要颤抖
  • 音量适中，不要太小
  • 语速适中，不要太快或太慢

2. 眼神

  • 跟对方建立眼神交流
  • 不要盯着天花板或地板
  • 不要频繁看手机或笔记

3. 姿势

  • 姿势从容，不要手足无措
  • 站直或坐直，不要驼背
  • 手势自然，不要僵硬

4. 态度

  • 相信自己——你的观点有价值
  • 不要道歉或自我贬低
  • 表达清晰，不要含糊

核心论点五：不同场景的即兴演讲

汉弗莱给出了几种常见场景的即兴演讲方法：

1. 面试

  • 方法：用”万能结构”回答任何问题
  • 举例：被问到”你有什么缺点”，用”观点-原因-例子-总结”来回答

2. 会议发言

  • 方法：先说”我的看法是…”，再用”三个要点”展开
  • 举例：“我对这个问题有三个看法：第一、第二、第三。”

3. 社交介绍

  • 方法：用一个”故事”介绍自己
  • 举例：“我叫XX，我做过最有趣的事情是…”——用故事让人记住你

4. 回应提问

  • 方法：先”肯定问题”，再”给出观点”
  • 举例：“这个问题很好，我的看法是…”

核心论点六：克服紧张的方法

汉弗莱给出了克服即兴演讲紧张的方法：

1. 不要追求”完美”

  • 即兴演讲不是”背诵”，不需要完美
  • 追求”清晰”和”真诚”比追求”完美”更重要

2. 不要”想太多”

  • 很多紧张是因为”想太多”——担心说错、担心被笑话
  • 实际上，没人在意你说的是否完美

3. 把注意力放在”内容”上

  • 不要关注”自己的表现”，而是关注”要传达的信息”
  • 当你专注于”内容”的时候，紧张感会降低

4. 提前”热身”

  • 在即兴演讲之前，先”热身”——比如自言自语、跟人聊天
  • 热身能让你的思维更活跃、表达更流畅

学姐私房话

以前我觉得”即兴发言”是”临场发挥”，不可能提前准备。

现在我明白了：即兴演讲不是”随机发挥”，而是有”套路”的——掌握了这个套路，你就能在任何场合都能清晰表达。
