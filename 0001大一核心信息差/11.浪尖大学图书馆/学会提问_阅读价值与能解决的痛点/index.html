学会提问_阅读价值与能解决的痛点

《学会提问》：我不再被人”割韭菜”，全靠这本书

说出来不怕你们笑话。

大一的时候，我被学长学姐”推销”了三次：

  • 一次是”原价500现价50”的英语课
  • 一次是”包过四六级”的复习资料
  • 一次是”学长创业急需用钱”的借钱求助

每次我都说”好”，事后才反应过来——我被骗了。

后来我读了这本书，才明白：我缺少的不是智商，而是一套”提问和思考”的方法。

先说说这本书讲什么

《学会提问》的作者是尼尔·布朗（Neil Browne）和斯图尔特·基利（Stuart Keeley）。

这本书被称为”批判性思维领域的圣经”，是哈佛大学等顶尖高校的必读书目。

核心思想只有一句话：

在一个信息爆炸的时代，最重要的能力不是”回答问题”，而是”提出问题”。

这本书能解决什么问题？

1. 总是被”忽悠”，交智商税？

你有没有过这种体验——

  • 商场促销”最后一天”，你冲进去买了
  • 网红推荐”超级好用”，你买回来发现是垃圾
  • 朋友说”这个项目稳赚”，你投了然后亏了
  • 商家说”不含任何添加剂”，你信了
  • 看到”研究表明…”就以为是真的

问题出在哪？

你没有用”批判性思维”过滤信息。

批判性思维的核心问题：

“这个结论是怎么得出的？证据是什么？这个证据可靠吗？”

学姐踩过的坑

大一我买过一套”学长”推荐的复习资料，200块。

学长说：“这套资料是我们团队整理的，命中率极高，原价599，现在只要200。”

我当时的反应：“哇，好便宜！学长不会骗我吧？”

结果呢？资料就是网上随便搜的，连排版都是乱的。

现在我学聪明了：

  • “这套资料为什么有效？”→ 证据在哪里？
  • “学长用了效果如何？”→ 有数据支撑吗？
  • “原价599怎么定的？”→ 有价格记录吗？

多问几个为什么，就不会被轻易忽悠了。

2. 不知道该相信谁，不知道什么是对的？

你有没有过这种体验——

  • 朋友圈说”A好”，微博说”B好”，你不知道信谁
  • 这个专家这么说，那个专家那么说，你不知道该听谁的
  • 公说公有理婆说婆有理，你不知道该站哪边
  • 网络上各种声音，你不知道该相信什么
  • 总是被”带节奏”，今天觉得这个对，明天觉得那个对

问题出在哪？

你没有自己的”判断标准”。

批判性思维教你的”判断标准”：

不是”相信谁”，而是”这个论证是否合理”。

判断一个观点是否可信，要看：

  1. 论题和结论是什么？
  2. 理由是什么？
  3. 理由是否充分？
  4. 有没有隐藏的假设？
  5. 有没有逻辑谬误？

3. 写论文/做研究不知道从哪里下手？

你有没有过这种体验——

  • 导师说”你去找相关研究”，你不知道找什么
  • 写论文不知道”论点”从哪里来
  • 做课题不知道”研究问题”怎么定
  • 看文献不知道”哪些是可靠的”
  • 写文献综述不知道”该怎么总结”

问题出在哪？

你没有学会”提问式思考”。

学术研究的第一步永远是”提问”：

  • “这个问题为什么重要？”
  • “前人是怎么研究的？”
  • “还有什么没解决的？”
  • “我的研究能贡献什么？”

学姐碎碎念

我大三写学年论文的时候，导师第一句话就是：

“你的研究问题是什么？”

我愣住了——我一直以为研究是”先看文献再总结”，原来研究是”先提问再找答案”。

读了这本书之后，我学会了：

  1. 提出问题：不是”学习有哪些方法”，而是”在线学习对大学生学习效果有什么影响”
  2. 评估证据：不是”XX说有效”，而是”有没有实证研究支持”
  3. 得出结论：不是”我觉得”，而是”基于证据，我认为”

论文一下子清晰多了。

4. 总是”随大流”，没有自己的观点？

你有没有过这种体验——

  • 室友/同学都在讨论一件事，你不知道该怎么看
  • 课堂上老师问”你怎么看”，你脑子一片空白
  • 和朋友争论，你总是”词穷”
  • 看到别人都在转发，你也想转发但不知道该不该转
  • 不知道自己的”观点”是什么

问题出在哪？

你没有学会”构建自己的论证”。

批判性思维教你”构建论证”：

结论（你的观点）
├── 理由1（为什么你这么认为）
│   └── 证据1（支持理由的数据/事实）
├── 理由2
│   └── 证据2
└── 理由3
    └── 证据3

当你能用自己的逻辑把这个结构搭出来，你就有了”自己的观点”。

大学生最该学的两个技能

技能1：识别”逻辑谬误”

常见的逻辑谬误：

谬误名称表现例子
诉诸权威用权威代替论证”哈佛教授说的一定对”
诉诸情感用情感代替论证”不买就是不爱国”
稻草人攻击对方弱化的观点”你说你想省钱？你就是抠门！“
人身攻击攻击提出观点的人”他长得那样，说的话能信？“
滑坡谬误假设一系列坏结果”今天允许迟到，明天就敢旷课”
两难选择假装只有两个选项”要么买，要么你就落后”

学会识别这些谬误，你就不会被轻易忽悠了。

技能2：提出”关键问题”

在听到一个观点时，学会问这几个问题：

  1. 论题是什么？ （这是关于什么问题的主张？）
  2. 结论是什么？ （他到底想让我相信什么？）
  3. 理由是什么？ （他用什么证据支持这个结论？）
  4. 证据可靠吗？ （这个证据是真的吗？）
  5. 有没有替代解释？ （有没有其他可能的原因？）

这本书适合谁读？

✅ “韭菜体质”——总是被忽悠、交智商税的人 ✅ “随大流”选手——没有自己观点的人 ✅ “不会写论文”选手——不知道如何构建论证的人 ✅ “信息焦虑”选手——不知道该信什么的人 ✅ “想独立思考”选手——想培养批判性思维的人 ✅ 即将写毕业论文的大学生

❌ 追求”标准答案”的同学——这本书教你提问，不是给你答案 ❌ 觉得”我不需要批判”的同学——批判性思维不等于”批判”

学姐私房话

读这本书最大的收获是什么？

我学会了”先思考，后行动”。

以前的我：

  • 听到”便宜” → 直接买
  • 听到”权威” → 直接信
  • 听到”大家都在” → 直接跟

现在的我：

  • 听到”便宜” → 问”为什么便宜”
  • 听到”权威” → 问”证据是什么”
  • 听到”大家都在” → 问”适不适合我”

问对了问题，就不会被轻易带偏。
