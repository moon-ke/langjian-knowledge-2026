1000「高价值」四级备考和考试技巧

四级备考全攻略：英语学霸学姐的高分秘诀

嗨，我是语嫣学姐。说到四六级，可能很多同学心里都有点发怵。但说实话，四级真的没有那么难——我当年四级裸考640，六级裸考610，虽然不算特别高，但应付考试足够了。今天就来跟大家聊聊，怎么用对方法，把四级轻松拿下。

一、先把考试情况搞清楚

1.1 考试时间安排

四六级每年两次考试：

  • 上半年：6月中旬（通常是6月13日左右）
  • 下半年：12月中旬（通常是12月12日左右）

2026年上半年四六级考试时间预计为6月13日，下半年预计为12月12日。 报名时间一般提前2-3个月，你们学校会发通知的。备考的话，建议提前3-4个月开始，不用太长，但也不能临时抱佛脚。

1.2 考试结构一览

题型内容题量分值比例时间
写作短文写作1题15%30分钟
听力短篇新闻7题 + 长对话8题 + 听力篇章10题25题35%25分钟
阅读选词填空 + 信息匹配 + 仔细阅读25题35%40分钟
翻译中译英段落翻译1题15%30分钟

总分710分，425分及格。 这个及格线要记住，很多学校四级不过不给学位证。

关键数据： 听力35%、阅读35%、写作翻译30%。听力阅读是大头，必须重点抓。

二、词汇：英语的根基

2.1 我的词汇学习方法

很多人问我怎么背单词，我的答案是：重复才是王道。

核心方法：

  • 不需要一天背200个新单词
  • 需要的是把200个单词反复看20遍
  • 用APP刷词，每天30-50个，碎片时间搞定

我用的APP是不背单词（名字很反讽是吧，但真的好用）。每天早上起来刷20分钟，晚上睡前刷20分钟，就这么简单。

2.2 核心词汇怎么记

四级核心词汇大概1500-2000个，必须掌握。我建议：

  1. 先刷高频词：哪些是高频词？历年真题里反复出现的词就是高频词
  2. 结合例句：光记单词没用，要记住它在句子里怎么用
  3. 注意一词多义：很多单词有好几个意思，都要看

学姐提醒： 四级阅读里经常出现熟词僻义，比如”book”不只是”书”，还有”预定”的意思。这种一定要专门积累。

2.3 词汇备考资源

  • 不背单词/扇贝英语：我用的两个APP，看个人喜好
  • 四级词汇词根词缀书：帮助理解单词构造，猜词用
  • 真题里积累：做真题时遇到的生词，全部记下来

三、听力：我的强项分享

3.1 听力核心技巧

说实话，四级听力没有大家想象的那么难。关键是掌握这几个技巧：

1. 预读题目（最关键！）

听力开始前有大约15秒的Directions时间，这个时间绝对不能浪费！

  • 快速扫读选项，圈出关键词
  • 预测对话或文章的主题
  • 特别注意时间、数字、人名等敏感信息

2. 抓住开头

听力的开头几句话往往包含重要信息，尤其是短篇新闻，导语部分（第一句话）基本就是核心内容。

3. 识别信号词

  • 转折词：but、however、although——后面是重点
  • 因果词：because、so、therefore——因果关系要记清
  • 顺序词：first、then、finally——时间线要理清

4. 同义替换意识

答案往往是原文的同义替换，不是原词重现。比如原文说”very important”，选项可能是”significant”。

3.2 听力各题型应对

短篇新闻（7题，7%）

  • 新闻的结构：导语 → 背景 → 详情 → 评论
  • 重点抓：时间、地点、人物、事件、数字
  • 多听BBC、VOA新闻，培养语感

长对话（8题，8%）

  • 注意对话中的问句，答案往往在回答里
  • but、however后面的内容是重点
  • 关注语气词（惊讶、感叹、强调）

听力篇章（10题，20%）

  • 这是听力的大头，分值最高
  • 主旨题看首尾句
  • 细节题听关键词
  • 推理题要理解言外之意

3.3 听力训练方法

精听：

  • 每天选一段真题听力
  • 先听1-2遍，理解大意
  • 然后逐句听写
  • 对照原文，标出听不出来的词
  • 反复听，直到完全听懂

泛听：

  • 平时走路、吃饭的时候听英语
  • BBC Learning English、VOA慢速英语都行
  • 不用刻意听懂，就当磨耳朵

学姐心得： 我从大一就开始每天泛听英语，刚开始什么都听不懂，但坚持半年下来，听力进步非常明显。这就是”慢功夫快效果”。

四、阅读：得阅读者得天下

4.1 阅读时间分配

四级阅读40分钟，分三个部分：

题型建议时间小技巧
选词填空8-10分钟最后做，性价比最低
信息匹配12-15分钟先看题目再读文章
仔细阅读15-18分钟先看题目再定位

4.2 仔细阅读（20%）—— 最核心

仔细阅读是四级阅读的重头戏，技巧就三个字：先看题。

做题步骤：

  1. 先看题目，圈出关键词（人名、数字、专有名词）
  2. 快速浏览文章首尾段和各段首句，把握主旨
  3. 用关键词回原文定位
  4. 仔细阅读定位句及其上下文
  5. 对比选项，选出同义替换最准确的

题型应对：

  • 细节题：准确定位，答案往往在定位句附近
  • 主旨题：看首尾段和每段首句
  • 推理题：不能选原文原话，要选合理推断
  • 词义题：联系上下文猜词义

4.3 信息匹配（10%）—— 最容易拿分

这道题最简单，但也是最容易丢分的，因为文章太长。

技巧：

  • 先看题目，划出10个关键词（人名、地名、数字、专有名词）
  • 然后扫读每段首尾句，找关键词匹配
  • 找到匹配就选，不用精读全文
  • 注意同义替换

4.4 选词填空（5%）—— 性价比最低

这道题分值最低，难度最大，建议最后做。

技巧：

  1. 先通读全文，把握主旨
  2. 分析每个空的词性（名词/动词/形容词/副词）
  3. 根据语法和语义双重判断
  4. 遇到不会的先跳过，回头用排除法

五、写作：套路为王

5.1 写作时间分配

30分钟写150词以上，时间很紧。我的分配是：

  • 审题+列提纲：5分钟
  • 写作：20分钟
  • 检查：5分钟

5.2 写作结构

四级作文基本就三种类型：议论文、图表作文、应用文。不管哪种，都用三段式：

开头： 描述现象/图表/引出观点（2-3句） 主体： 分析原因/对比/阐述观点（3-4句） 结尾： 总结观点/提出建议（2-3句）

5.3 写作高分技巧

1. 用高级词汇替换低级词汇

低级表达高级替换
importantsignificant、crucial、vital
manynumerous、a multitude of
thinkargue、believe、hold the view
goodbeneficial、advantageous、favorable

2. 用复杂句式

  • 从句：Although…, while…, because…
  • 倒装句：Only in this way can we…
  • 强调句：It is…that…

3. 背模板但不死套

开头结尾都有固定句式可以套用，但中间段要灵活发挥。

5.4 写作备考方法

  • 背范文：每周背2-3篇真题范文，积累好词好句
  • 仿写练习：看完范文后，自己仿写一篇类似话题
  • 计时写作：考试前每周至少写一篇，控制时间

六、翻译：容易翻车的地方

6.1 翻译核心技巧

翻译最重要的是两个字：通顺。

原则：

  • 忠实原则：准确表达原文意思，不增不减
  • 通顺原则：译文符合英语表达习惯
  • 简洁原则：能用简单句就别用复杂句

6.2 翻译常见难点

1. 中国特色词汇

这类词经常考，比如：

  • 灯笼 → lantern
  • 饺子 → dumpling
  • 红包 → red envelope
  • 春晚 → Spring Festival Gala

2. 长句拆分

中文爱用长句，英文要拆成短句：

  • 找主谓宾
  • 先翻译主干
  • 再补充修饰成分

3. 固定搭配

注意中英表达差异：

  • “提高效率” → improve efficiency（不是raise efficiency）
  • “采取行动” → take action（不是make action）

6.3 翻译备考方法

  • 每天练习一段：用真题翻译题练习
  • 积累中国特色词汇：整理一份专属词汇表
  • 对照参考译文：看看自己的翻译和标准答案差在哪里

七、备考计划（三个月版本）

7.1 第一阶段（第1-4周）：打基础

目标： 背完核心词汇，熟悉考试结构

每日任务时长
背单词（APP）30分钟
听力泛听20分钟
阅读1-2篇20分钟
周末做一套真题2小时

7.2 第二阶段（第5-8周）：强化训练

目标： 各题型技巧突破，提高准确率

每日任务时长
背单词（复习+新词）20分钟
听力精听30分钟
阅读2篇+精读分析30分钟
写作或翻译练习20分钟
周末做一套真题2小时

7.3 第三阶段（第9-12周）：冲刺模拟

目标： 全真模拟，查漏补缺

每日任务时长
词汇查漏补缺15分钟
听力真题练习30分钟
阅读限时训练30分钟
写作/翻译专项30分钟
每周2-3套全真模拟3-4小时

考前一周： 调整作息，每天做一套题保持手感，复习错题本。

八、考场实战技巧

8.1 时间把控

四级考试时间非常紧，必须严格控制：

  • 写作：30分钟一到立刻停笔，开始听力
  • 听力：25分钟，结束后收答题卡1，不能拖延
  • 阅读+翻译：70分钟，三部分按顺序做或先做仔细阅读

8.2 答题顺序建议

我的建议：

  1. 仔细阅读（20%，最重要）
  2. 信息匹配（10%，最简单）
  3. 翻译（15%，最后做）
  4. 选词填空（5%，性价比最低）

8.3 考场注意事项

  • 带好证件：准考证+身份证
  • 带好耳机：有些学校用调频耳机，提前测试电量
  • 准备2B铅笔和黑色签字笔
  • 提前到场：熟悉环境，调整状态
  • 控制节奏：别在某道题上死磕

8.4 心态调整

  • 深呼吸：进考场前深呼吸3-5次
  • 积极暗示：告诉自己”我能行”
  • 别受他人影响：旁边同学翻卷子不用慌，按自己节奏来

九、常见问题解答

Q：听力速度太快跟不上怎么办？ A：从VOA慢速开始练起，逐步过渡到正常语速。坚持精听训练，半年后你会发现四级听力真的很慢。

Q：阅读做不完怎么办？ A：用”先看题再定位”的方法，不用通读全文。准确定位后仔细读定位句就行，速度能快一倍。

Q：作文写不够字数怎么办？ A：平时多积累好词好句，考试时尽量用复杂句式。实在写不够，就把观点展开多说几句。

Q：翻译遇到不会的词怎么办？ A：意译！把不会的词用你会的词解释出来，意思对就行。比如”火锅”不会，翻成”a popular Chinese food”也能得分。

总结

四级备考，核心就几点：

  1. 词汇是根基：每天背，坚持三个月
  2. 听力靠精听：每天一段，逐句听写
  3. 阅读讲技巧：先看题再定位
  4. 写译靠积累：多背多练多模仿

英语这东西，没有捷径，只有重复。把简单的事情重复做，你就是专家。
