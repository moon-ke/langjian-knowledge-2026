1000「高价值」英语四六级备考攻略

英语四六级备考攻略：从小白到600+

作者：语嫣学姐 | 英语学霸型 | 四级650分、六级625分 | 专四良好通过

先回答几个问题

四六级到底有多重要？

很多人觉得四六级只是一张证书，考过了就行。但实际上：

四六级成绩的影响：

  • 保研：大多数学校要求六级通过（425分以上），部分985/211要求500+甚至600+
  • 考研：部分导师会看英语成绩
  • 就业：外企、国企、合资企业招聘必看
  • 出国：雅思/托福的基础

所以，四六级真的很重要。 建议在大二之前全部通过，越早越好。

四级和六级哪个更难？

差了不止一个档次。

  • 四级：相当于高考英语难度，稍高于高考
  • 六级：词汇量要求从4500提升到6000，题目难度和深度大幅增加

我见过很多同学四级500多分飘过，六级考了三四次都没过。所以，不要轻视六级。

一、了解考试结构

四六级考试结构对比

部分题型时长分值
听力短篇新闻、长对话、短文25分钟35%
阅读选词填空、长篇阅读、仔细阅读40分钟35%
写译写作、翻译25分钟30%

各部分时间分配

  • 听力：25分钟（边听边涂卡，没有额外涂卡时间）
  • 阅读：40分钟（选词10分钟、长篇10分钟、仔细阅读20分钟）
  • 写作：30分钟
  • 翻译：25分钟

二、单词怎么背？

背单词的重要性

单词是英语的基础，没有词汇量，一切技巧都是空谈。

四级的词汇要求：约4500词 六级的词汇要求：约6000词

推荐方法一：词根词缀法

很多单词可以用词根词缀拆解，理解了构词法，单词不再需要死记硬背。

常见词根：

  • pro- 表示”向前”
  • -tion 表示名词后缀
  • -ive 表示形容词后缀

举例：

develop = de（展开）+ velop（卷）→ 发展 export = ex（出）+ port（拿）→ 出口

推荐方法二：语境记忆

把单词放在句子、短文里记忆，比单独背单词有效得多。

具体操作：

  • 用单词APP的例句功能
  • 阅读时遇到生词查词典，把例句读一遍
  • 把单词写进自己的句子

推荐方法三：艾宾浩斯遗忘曲线

背单词要复习，否则会遗忘。

背单词计划：

  • 当天背新词
  • 第2天复习第1天的词，同时背新词
  • 第4天复习前3天的词
  • 第7天再复习一遍
  • 第15天再复习一遍

坚持下来，你会感谢自己。

单词书/APP推荐

  • 单词书：新东方四六级词汇乱序版、星火英语词汇
  • APP：不背单词、墨墨背单词、百词斩
  • 小程序：扇贝单词

三、听力怎么练？

听力是最容易拉分的部分

很多人听力不好，是因为听得太少。

解决方法是：每天听。

练习方法

精听：

  1. 先完整听一遍，了解大意
  2. 再听一遍，一句一句地听写
  3. 对照原文，标出没听出来的词
  4. 反复听没听出来的句子，直到完全听懂
  5. 最后完整听一遍

泛听：

  • 每天起床后、睡前听15-30分钟
  • 材料可以是：BBC、VOA慢速英语、四六级真题听力
  • 泛听的目的是磨耳朵，不需要完全听懂

听力技巧

预览选项： 在听力开始前，快速浏览选项，猜测对话/短文的主题。

关键词定位： 听到选项中的关键词时，集中注意力，往往答案就在附近。

常见陷阱：

  • 数字类：注意单位（percent/per/thousand/million）
  • 转折词后：but/however/actually后面往往是答案
  • 同义替换：原文的词可能在选项中换成同义词

四、阅读怎么练？

三种阅读题型

选词填空（10选10）：

  • 先判断每个词的词性（名词/动词/形容词/副词）
  • 再根据上下文选词
  • 这道题分值最低（5%），不要花太多时间

长篇阅读（信息匹配）：

  • 先读题目，划出关键词
  • 再去文章中找匹配的段落
  • 关键词匹配是核心技巧

仔细阅读（传统阅读理解）：

  • 先读题干，再读文章
  • 带着问题去文章中找答案
  • 答案一般按顺序出现

阅读提速技巧

扩大视幅： 不要逐字阅读，而是每次看一整个句子或一个意群。

减少回读： 遇到不懂的词，先跳过，根据上下文猜意思。如果回读超过3次还不懂，再查词典。

限时阅读： 练习时要计时，四级仔细阅读8分钟/篇，六级仔细阅读10分钟/篇。

五、写作怎么练？

写作是最好提分的部分

很多人写作不好，是因为练得太少。

解决方法是：每周写一篇。

写作结构

经典三段式：

第一段：引入话题 + 表明观点
第二段：论据1 + 论据2 + 论据3
第三段：总结观点 + 升华

常用句型模板

引入话题：

  • Currently, there is a growing concern about…
  • Recently, the issue of … has been brought into focus.

表明观点：

  • As far as I am concerned, …
  • From my perspective, …
  • In my opinion, …

列举论据：

  • First and foremost,…
  • Furthermore,…
  • Last but not least,…

总结观点：

  • In conclusion,…
  • To sum up,…
  • In a word,…

高级词汇替换

让你的作文从”及格”到”高分”：

低级表达高级替换
importantsignificant / crucial / essential
manynumerous / a large number of
thinkhold the view that / maintain / reckon
goodbeneficial / advantageous / favorable
baddetrimental / unfavorable / adverse
differentvarious / diverse / distinct

练习方法

  1. 每周写一篇真题作文
  2. 用上述句型替换简单表达
  3. 写完后用Grammarly检查语法
  4. 背几篇范文，模仿结构

六、翻译怎么练？

翻译题型特点

翻译是中译英，题材涉及中国的政治、经济、文化、历史、社会。

翻译技巧

拆分句子： 中文句子往往很长，要先拆分，再翻译。

注意时态： 中文没有时态，但英文有时态。要根据上下文判断。

专有名词：

  • 中国特色词汇：需要平时积累
  • 常见表达：中华文化、文明、传统、四大发明

七、备考时间规划

三个月备考计划

第一个月：打基础

  • 每天背50个单词
  • 每天做一篇听力精听
  • 每天读一篇英文文章

第二个月：专项训练

  • 听力：每天一套听力题
  • 阅读：每天一套阅读题
  • 写译：每周两篇作文+两篇翻译

第三个月：冲刺模拟

  • 每周做两套完整真题
  • 严格按照考试时间
  • 做完认真分析错题

考前一周

  • 每天做一套听力，保持语感
  • 复习高频单词
  • 准备作文模板
  • 调整作息，早睡早起

九、常见问题

问题一：单词背了总是忘怎么办？

这是正常的。单词需要反复记忆，用艾宾浩斯遗忘曲线的方法，坚持复习。

问题二：听力完全听不懂怎么办？

先从简单的材料开始，比如VOA慢速英语。等听力有进步了，再换回四六级真题。

问题三：作文写不出东西怎么办？

背模板，背范文，仿写。肚子里有货了，自然能写出来。

问题四：要不要报班？

如果自律性差，可以报班。但其实四六级不用报班，自己复习完全够用。

碎碎念

我第一次考六级的时候，只考了460分，离600分差得远。

后来我分析了原因：单词没背完，听力练得太少，写作全是简单句。

第二次备考的时候，我每天背单词，每天练听力，每周写两篇作文。坚持了三个月，最后考了625分。

四六级真的没有那么难，难的是坚持。

希望你也能找到适合自己的方法，一次就考到理想的分数。
