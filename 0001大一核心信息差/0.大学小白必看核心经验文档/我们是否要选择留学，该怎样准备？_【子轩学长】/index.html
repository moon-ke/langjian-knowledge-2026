我们是否要选择留学，该怎样准备？

说实话，“要不要留学”这个问题，我被问了无数遍。

每次学弟学妹来问我，我第一句话都是：“你先告诉我，你为什么想留学？”

很多人答不上来。

他们会说：“大家都说留学好”、“镀个金回来好找工作”、“我妈让我去的”……

如果你也是这种想法，那我建议你先把这篇文章看完，再决定要不要留学。

一、留学的意义到底是什么？

在回答”要不要留学”之前，你先要想清楚，留学对你意味着什么。

根据我的经验，留学大概有三种意义：

1. 学术提升型

你想去世界顶尖学府学最前沿的知识，以后从事科研或者学术道路。

这种留学，值。

美国MIT、斯坦福，英国牛津、剑桥，德国TU9……这些学校的学术资源，确实是世界顶尖的。

2. 职业跳板型

你想通过留学提升学历，回国后进入更好的平台。或者你想留在当地工作，移民海外。

这种留学，值不值取决于你去的学校和你的专业。

不是所有海归都吃香。如果你去的是野鸡大学的水专业，回国可能还不如985本科好找工作。

3. 体验成长型

你想体验不同的文化，开阔眼界，顺便提升一下自己。

这种留学，我觉得值。

但前提是：你家经济条件允许。体验很重要，但不值得你砸锅卖铁。

二、什么人适合留学？

适合留学的人

  1. 有明确目标——你知道留学能帮你实现什么
  2. 学习能力强——能适应不同的教学方式
  3. 心理承受力强——能接受孤独和挫折
  4. 家里经济允许——不用为了钱太焦虑
  5. 英语/小语种有一定基础——不然上课都听不懂

不适合留学的人

  1. 家里经济压力大——留学不值得你让全家返贫
  2. 只是”随大流”——别人留我也留，大概率后悔
  3. 逃避国内升学失败——留学不会让你的问题消失
  4. 自律性差——没人管你，你可能天天在家打游戏
  5. 语言完全不行——出去之后上课听不懂，生活更痛苦

四、留学申请Timeline

留学申请是一场持久战，我建议从大一就开始规划。

大一：探索期

  • 保持高GPA（越高越好，最低3.0+）
  • 开始学英语（四六级、托福/雅思入门）
  • 了解留学基本概念（国家、学校、专业）
  • 参加社团活动，积累软背景

大二：准备期

  • 托福/雅思首考（目标分数：托福100+/雅思7.0+）
  • GRE/GMAT首考（理工科考GRE，商科考GMAT）
  • 开始做科研或实习
  • 参加交换生项目（如果有的话）

大三：冲刺期

  • 托福/雅思刷分（可以多考几次）
  • GRE/GMAT刷分（目标：GRE 325+/GMAT 700+）
  • 科研出成果（论文、专利）
  • 实习经历（至少2段）
  • 确定申请学校名单

大三暑假：文书期

  • 写个人陈述（Personal Statement）
  • 写简历（Resume/CV）
  • 联系推荐人（教授、实习上司）
  • 开成绩单、在读证明
  • 开始网申

大四上：申请期

  • 提交申请（通常9月-次年1月）
  • 准备面试（部分学校需要）
  • 等待offer
  • 选定学校，交占位费

大四下：行前期

  • 办签证
  • 订机票、找房子
  • 体检、打疫苗
  • 准备行李

五、语言考试怎么准备？

托福 vs 雅思

项目托福雅思
适用地区美国为主，全球认可英国/澳洲/加拿大为主，全球认可
考试形式机考纸笔或机考
难度学术性强，听力要求高日常对话多，口语真人对话
建议听力好的同学考托福口语好的同学考雅思

我的建议： 2026年托福评分体系改革，改成1-6分等级制。具体影响还不确定，建议提前关注官方通知。

GRE vs GMAT

项目GREGMAT
适用专业文理工商皆可商科MBA为主
数学难度较难中等
语文难度词汇量大逻辑要求高
有效期5年5年

我的建议： 理工科、文科申研考GRE；商科申MBA考GMAT。但现在很多商学院也接受GRE了。

六、文书怎么写？

说实话，留学申请中，文书比成绩更重要。

你的GPA、托福成绩可能跟别人差不多，但一份好的文书能让你脱颖而出。

个人陈述（PS）结构

  1. 开头：用一个故事或经历引出你的兴趣
  2. 学术背景：你学过什么，做过什么研究
  3. 实习/工作经历：你做过什么项目，有什么收获
  4. 未来规划：你想学什么，以后想做什么
  5. 为什么选这个学校：为什么你适合这个项目

注意事项

  • 不要模板化——招生官一天看几百份PS，模板化的直接pass
  • 展示个性——你是谁？你跟别人有什么不同？
  • 具体例子——不要只说”我很努力”，要说你怎么努力的
  • 扬长避短——GPA低可以解释，科研少可以强调其他方面
  • 反复修改——好的PS都是改出来的，至少改10遍

七、DIY还是找中介？

DIY

适合的人：

  • 英语好，能自己写文书
  • 时间管理能力强
  • 信息检索能力强
  • 申请的学校数量不多

优点： 省中介费（2-5万），锻炼能力，文书自己把控 缺点： 费时间，可能踩坑

中介

适合的人：

  • 英语一般，文书写不好
  • 申请学校数量多（10所以上）
  • 时间紧，还在同时准备考研/保研
  • 不了解申请流程

优点： 省心，有经验 缺点： 贵，质量参差不齐，可能坑你

我的选择： DIY。

我DIY申请了MIT、哥大、LSE，最后都拿到了offer。过程很累，但学到很多东西。

如果你决定找中介，记住：中介只是帮你处理流程，文书必须自己把关。很多中介的文书模板化严重，你要亲自审核。

八、常见问题Q&A

Q： 双非能申到好学校吗？

A： 能，但难度大。英国卡list，双非可能被挡在门外。美国相对友好，但需要你有亮眼的软背景（科研、实习、竞赛）。

Q： GPA 3.0够吗？

A： 顶尖名校基本不够。最低要求通常是3.0，但实际录取均值在3.5以上。3.0只能申请很普通的学校。

Q： 实习重要还是科研重要？

A： 看专业。商科、传媒类实习更重要；理工科、科研型硕士科研更重要。

Q： 推荐信找谁写？

A： 最好找了解你的教授或实习上司。头衔大的教授不如了解你的教授有用。

九、真心话

说实话，留学这条路不好走。

申请的时候很焦虑，等offer的时候更焦虑，出去之后适应期最难熬。

但如果你真的想清楚了，留学能带给你的，真的比你想象的多。

最后送你三句话：

  1. 留学不是目的，是手段——想清楚你想要什么
  2. 早规划，早准备——别到大三才着急
  3. 信息差就是分数——多问学长学姐，多看官网通知

子轩学长踩过的坑

我DIY申请的时候，因为不熟悉流程，差点错过哥大的截止日期。

那时候我以为美国学校都是统一截止日期，结果哥大的金融项目是rolling录取，先到先得。

我晚交了3天，差点就没机会了。

教训是：申请之前一定要仔细看每个学校的截止日期，不要想当然。
