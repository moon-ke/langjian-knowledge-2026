大学奖学金申请指南：这些钱你可以拿到

说实话，奖学金这件事，我真的是大三大四才搞明白的。

大一的时候我以为奖学金都是给「学霸」的，跟我这种中等生没关系。

后来我才知道，奖学金不只是看成绩，还有很多类型。

我大三那年拿了8000块的国家励志奖学金，加上学校的奖学金，一年拿了12000。

今天把这些经验分享给你。

奖学金有哪些类型？

国家层面

国家奖学金

  • 金额：8000元/年
  • 名额：很少（每个学院每年几个）
  • 要求：成绩+综合素质全面发展
  • 难度：★★★★★

国家励志奖学金

  • 金额：5000元/年
  • 名额：较多（每个班级1-2个）
  • 要求：成绩优秀+家庭经济困难
  • 难度：★★★★

学校层面

学业奖学金

  • 金额：1000-5000元不等
  • 名额：较多
  • 要求：成绩为主要标准
  • 难度：★★★

社会奖学金

  • 金额：不定（1000-20000都有）
  • 名额：看具体情况
  • 要求：企业/校友设立，各有标准
  • 难度：★★★

学院层面

单项奖学金

  • 金额：一般500-2000元
  • 名额：多
  • 类型：学习进步、社会工作、文体活动、科技创新等
  • 难度：★★

评比规则怎么算分？

学姐踩过的坑

大二的时候我以为奖学金就是看成绩。

结果我成绩班级第三，但综测排名只有第十。

因为我综测加分太少了，别人参加比赛加分、加权加分，我什么都没有。

教训是：奖学金不只是看成绩，综测加分很重要！

综测加分项

学业成绩

  • 成绩越高，分数越高
  • 一般占综测的60-70%

科研竞赛

  • 论文发表：省刊/核心期刊/SCI不同级别
  • 学科竞赛：校级/省级/国家级
  • 大创项目：校级/省级/国家级

社会工作

  • 学生会干部、班干部
  • 社团负责人
  • 志愿者活动

文体活动

  • 运动会获奖
  • 文艺比赛
  • 其他校园活动

各类加分参考

类别加分幅度
国家级竞赛一等奖10-15分
省级竞赛一等奖5-8分
校级竞赛一等奖2-4分
核心期刊论文10-20分
发明专利10-15分
学生会主席5-8分
班长/团支书3-5分

如何提高竞争力？

策略1：成绩是基础

不管什么奖学金，成绩都不能太差。

建议：保持班级前30%，比较好的。

策略2：参加科研竞赛

这是我最推荐的方式。

为什么？

  • 加分多
  • 对保研/留学都有用
  • 能学到东西

推荐参加的比赛：

  • 大创（大学生创新创业项目）
  • 挑战杯/互联网+
  • 学科竞赛（数学建模、英语竞赛等）
  • 专业相关的技能大赛

策略3：担任学生干部

  • 班长、团支书加分多
  • 学生会干部也行
  • 但不要为了加分当干部，要真的做事情

策略4：关注社会奖学金

很多企业/校友会设立奖学金，名额多、金额高。

怎么知道？

  • 辅导员会发通知
  • 学校官网/官微
  • 学院公告栏

申请材料怎么写？

基本材料

  1. 奖学金申请表 - 按要求填写
  2. 成绩单 - 教务处打印
  3. 获奖证书复印件 - 整理好，按时间顺序
  4. 个人陈述 - 说明自己的优势和努力

申请时间线

时间任务
每年9月关注通知，准备材料
9月中下旬提交申请
10月评审、公示
11月发放奖学金

学姐私房话

说实话，奖学金这件事，真的是「早规划早受益」。

大一开始就要了解规则，为之努力。

我大一大二的时候不懂，结果综测加分少得可怜。

后来大三大四才发力，虽然也拿了一些奖学金，但错过了很多机会。

所以，从大一开始：

  1. 了解学校的奖学金政策
  2. 看看评比规则，哪些可以加分
  3. 制定计划，有针对性地努力
