考研学费、奖助金与生活成本信息差

我当年考研的时候压根没想过读研要多少钱。一心想着考上了再说，结果上岸之后一看账单，整个人都傻了。学费、住宿费、生活费加起来，比本科贵了不止一个档次。所以今天跟你聊聊读研期间的经济问题，让你心里有个底。

一，学费：差距比你想象的大

学硕学费

学硕按国家统一标准，一般每年8000块钱，三年下来24000左右。文科专业学费可能低点，每年6000，理工科基本都是8000这个标准。

专硕学费

专硕就复杂了，不同专业差距天上地下。

普通专硕每年1万到15000，比如工程、教育这些专业。

热门专业就贵了：金融硕士、人工智能硕士，每年3万到10万不等。

MBA更离谱，普通学校一年四五万，顶尖学校的MBA项目能到几十万。听过最夸张的一个项目，两年学费60万，读个MBA比买套房还贵。

非全日制

非全日制学费比全日制还高，因为主要是给在职人员读的，人家不差钱。

但提醒一句：非全日制找工作的时候很受歧视，很多企业不认。你要是想提升学历走这条路可以，要是想靠这个翻身，找工作的时候可能会失望。

二，奖助金：这些钱你可以拿

国家奖学金

这是最香的一项，每年2万（硕士）或3万（博士）。

但竞争也激烈，全国每年硕士奖励7万名左右。想想，每年几百万研究生，就7万人能拿这钱。想拿国奖？成绩拔尖、科研突出是基本门槛。

学业奖学金

覆盖面更广一点。中央高校的硕士生学业奖学金，最高每年2万。当然不是所有人都能拿最高档，大部分人拿的是几千块。

奖学金分配向基础学科、拔尖创新人才倾斜。越是冷门专业、越是学术型人才，拿到的越多。

国家助学金

这是兜底的，全覆盖（全日制非定向研究生）。硕士每年至少6000，博士每年至少10000。按月发放，每月500到1000不等。虽然不多，但至少能覆盖食堂吃饭了。

三助岗位

助研、助教、助管，简称”三助”。

参与导师的科研项目，可以拿助研津贴。帮老师批改作业、当助教，也能拿钱。参与学校管理当助管，也有补贴。

理工科学生参与导师项目的机会多，助研津贴往往更可观。文科学生可以多关注助教和助管岗位。

三，生活成本：城市差异巨大

住宿费

校内宿舍便宜，每年800到1500。分摊到每月，七八十块钱。

但问题来了：京沪地区的一些院校，不给专硕提供宿舍了。你得自己出去租房子。这个就贵了，一线城市单间每月1500到3000，三年下来五六万到十万。

吃饭

食堂便宜，每月900到1500够用。天天外卖、下馆子的话，那没上限了。

总体生活成本

一线城市：每月2500到3000，三年下来9万到10万。

新一线城市：每月1200到1800，三年4万到6万。

三四线城市：每月800到1500，三年3万到5万。

四，这些钱你要心里有数

读研三年，总体花费大概是多少？

最省钱的方案：学硕 + 校内住宿 + 食堂吃饭

  • 学费：8000×3 = 24000
  • 住宿：1000×3 = 3000
  • 生活费：1200×36 = 43200
  • 总计：约7万

普通方案：专硕 + 校外租房 + 正常消费

  • 学费：15000×3 = 45000
  • 住宿：2000×36 = 72000（校外）
  • 生活费：2000×36 = 72000
  • 总计：约19万

差距有多大，你自己算算。

五，怎么缓解经济压力

奖学金冲一冲

成绩好的同学，学业奖学金每年能拿几千到两万。努努力，这钱还是能拿到的。

助学贷款

全日制研究生可以申请国家助学贷款，每年最高25000。在校期间利息国家替你付，毕业后才开始还。这钱你要是缺，可以考虑。

兼职和实习

研究生期间完全可以实习，尤其是专硕。实习不仅能赚钱，还能积累工作经验，为以后找工作打基础。但别因为兼职影响学业，读研的首要任务是毕业和搞科研，别本末倒置。

跟导师好好处

导师项目多的话，助研津贴会比较可观。但这事儿可遇不可求，看你的导师是哪种类型。

读研确实要花钱，但也没你想象的那么可怕。奖助金体系覆盖得还不错，再加上实习、兼职，大部分人读下来不至于揭不开锅。

关键是提前规划，知道大概要花多少钱，心里有底，就不会到时候手忙脚乱。

别为了省钱影响学业，读研的目的是提升自己，不是为了省钱把自己搞得苦哈哈的。祝你读研顺利，经济无压力！
